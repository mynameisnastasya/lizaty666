# liz_ty666 — education-first website

Премиальный русскоязычный сайт личного бренда Лизы с главным фокусом на обучении астрологии.

## Продуктовая логика

`контент → доверие к Лизе → интерес к методу → выбор уровня → обучение`

Консультации, руны и свечные практики сохранены как отдельные вторичные ветки и больше не конкурируют с образовательными программами на главной.

## Основные страницы

- `/` — метод, точки входа, флагман, доказательства и главный CTA;
- `/education.html` — полный маршрут обучения, программы, сравнение, модули и FAQ;
- `/professional-program.html` — отдельная страница флагманской программы;
- `/astrology.html` — астрологические консультации;
- `/practices.html` — руны, свечи и практики;
- `/about.html` — Лиза и ход её мышления;
- `/reviews.html` — первичный канал отзывов и система кейсов;
- `/faq.html` — обучение, консультации и этические границы;
- `/contacts.html` — маршрутизация обращений в Telegram.

Старые адреса `/runes.html` и `/candles.html` перенаправляют в соответствующие разделы `/practices.html`.

## Дизайн-система

Направление: **dark editorial × living archive × orbital scrapbook**.

- Obsidian `#0C0B0C`;
- Warm milk `#EDE4D7`;
- Liza red `#B41628`;
- Deep wine `#7D1019`;
- Dela Gothic One + Onest + точечный Caveat;
- тонкая орбита с одной красной точкой как повторяющийся мотив.

Основные файлы системы: `editorial.css` и `site.js`.

## Диагностика обучения

CTA «Подобрать обучение» открывает трёхшаговый сценарий:

1. текущий уровень;
2. цель;
3. имя и удобный контакт.

После подтверждения открывается Telegram с готовым сообщением. Данные не отправляются на внешний сервер сайта.

## Технологии

- чистый HTML, CSS и vanilla JavaScript;
- публикация через GitHub Pages: `https://mynameisnastasya.github.io/lizaty666/`;
- responsive layout от 390 px;
- semantic HTML, keyboard navigation и `prefers-reduced-motion`;
- Open Graph, canonical URLs, sitemap и базовая schema.org-разметка.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте `http://localhost:4173`.
