# Путь нового покупателя

1. **Бот** `/start` → что такое ASTRODAY, 3 шага, кнопки «Анкета и кабинет» (Mini App `/login`) и «Тарифы».
2. **Привязка Telegram**: Mini App передаёт подписанный `initData` (≤5 минут) → сессия на 14 дней. С сайта вне Telegram —
   ссылка `t.me/Lizty666bot?start=login_<код>` (10 минут). Идентификатор — подтверждённый Telegram ID, не username.
3. **Анкета**: имя, дата, время (можно «не знаю»), город из справочника GeoNames (координаты и исторический часовой пояс
   берутся из справочника), часовой пояс и час доставки, согласия. Местное время → UTC по базе часовых поясов
   с отказом на несуществующее/двусмысленное время (переходы часов).
4. **Тариф и оплата** на `/checkout`: сервер берёт цену из каталога (1 666 / 3 666 / 6 666 ₽), создаёт заказ
   с Idempotency-Key (повторное нажатие не создаёт второй платёж), чек на e-mail, переход в YooKassa. Разовая оплата
   за срок, без автопродления.
5. **Подтверждение**: webhook YooKassa → сервер запрашивает платёж у YooKassa и сверяет всё; если человек закрыл
   браузер — планировщик сверит сам. Доступ выдаётся один раз, в той же транзакции создаётся задача выполнения.
6. **Сразу после оплаты**: в Telegram «Оплата прошла ✅, доступ до …», затем расчёт карты на сегодня, текст Лизы
   (OpenAI по рассчитанным фактам, проверка) и первый прогноз — обычно в течение пары минут.
7. **Дальше**: каждый день в выбранный час по выбранному часовому поясу. `/today` — посмотреть в любой момент,
   `/stop` / `/resume` — пауза, `/status` — всё о доступе.

Если оплатили раньше анкеты (возможно при входе через другой канал): доступ не теряется, задача ждёт анкету
и продолжится сама; в Telegram — кнопка «Заполнить анкету».
