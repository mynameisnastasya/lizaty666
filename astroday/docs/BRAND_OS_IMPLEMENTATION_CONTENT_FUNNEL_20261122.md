## 2. Сильный оффер (гипотеза, не подтверждённый research)
- **Кому:** человеку, которому интересна персональная астрологическая практика.
- **В ситуации:** общие гороскопы слишком обезличены; хочется понять, что рассчитано именно для своей карты.
- **Ценный переход:** от случайного текста в ленте к личному, последовательному материалу, который можно спокойно прочитать и осмыслить.
- **Механизм:** дата и место рождения (+ время, если известно), расчёт положений и аспектов, проверка фактов, авторский язык интерпретации.
- **Формат и срок:** пробный прогноз; далее материалы согласно выбранному сроку и текущему доступу. Рассылка по согласию.
- **Почему доверять:** прозрачный путь к продукту и проверяемость расчётных данных; никаких несуществующих отзывов или гарантий.

Короткая фраза для пересказа: **«ASTRODAY — личная астрология по твоей карте рождения, не общий гороскоп для всех»**.

## 4. Четыре смысловые линии бренда
1. **Взгляд.** «Почему общая фраза для всех Овнов ничего не говорит о твоей индивидуальной карте»; «что можно и нельзя ожидать от астрологического текста»; «зачем нужны прозрачные ограничения».
2. **Метод.** «Из каких исходных данных собирается натальная карта»; «что такое аспекты в астрологической практике»; «как поступаем, если время рождения неизвестно»; «почему делаем редакторскую проверку».
3. **Доказательства.** Видео реального прохода по кабинету; демонстрация пробного прогноза на синтетическом профиле; пример исправленной ошибки расчёта; реальная обратная связь с разрешения.
4. **Личность.** Почему Лиза делает этот продукт; её личный выбор стандартов и голоса; границы между личной жизнью и профессией. **Личную историю, убеждения и роль нельзя выдумывать.** Получить её формулировки у владелицы.

Каждая линия должна вести к осмысленному следующему шагу, а не к пустым охватам.

## 6. Путь конверсии и экономическая логика
`Контент → профиль/бот → /astroday-method → /login → анкета → пробный прогноз → /checkout → оплата → первый материал → повторное чтение → добровольное продление`.

- Метрики: число уникальных входов, подтверждённых сессий, готовых анкет, успешно открытых проб, переходов в checkout, успешных оплат, выручка после возвратов, стоимость привлечения, возвраты пользователей на 7-й и 30-й день, доля доставок без ошибок. 
- Все метрики считать агрегированно, не передавать дату рождения, Telegram initData или платёжные реквизиты сторонним трекерам.
- Примеры экономики из PDF — **арифметические сценарии**, а не обещания: выручка = число продаж × реальный средний чек. Для 200 000 ₽ при чеке 2 000 ₽ потребуется 100 продаж *до учёта комиссий и затрат*.
- Сначала проверять качество и конверсию существующего продукта, затем масштабировать каналы.

## 7. Три спринта из PDF на 90 дней
**Недели 1–2. Основа:** уточнить позиционирование, один оффер, список доказательств, реальные условия тарифа, кросс-платформенный тест на мобильном. Критерий: новый пользователь понимает продукт и доходит до пробы без тупика.

**Недели 3–6. Рынок:** 10–15 разговоров, первые прямые предложения без давления, 4 смысловые линии контента, разбор возражений, пилотирование новых подсказок. Критерий: появляются проверяемые данные по конверсии и реальная обратная связь.

**Недели 7–12. Система:** стандартизировать редактуру и поддержку, сформировать банк доказательств, измерять возвращаемость, выбрать вторую площадку только по данным, уточнить путь продления. Критерий: стабильная доставка, понятная экономика и причины остаться.
