## Известные ограничения
- Позднее окно рассылки тестерам в `daily7`. Развёрнутая версия V2 отправляет только 07:00–07:19 по Кемерово, а в r2 было до 12:00. Для пользователей v2 это неактуально: их рассылка с окном до 12 часов.
- Текущий город: у части анкет нет `current_lat/lon`, тогда лунные сутки считаются по столице часового пояса (с пометкой в календаре).
