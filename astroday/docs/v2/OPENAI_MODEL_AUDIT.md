## 4. Стоимость (оценка)
Официальной страницы цен из сессии получить не удалось. Сторонний источник ([eesel.ai, 08.09.2026](https://www.eesel.ai/blog/gpt-6-astra-pricing)) приводит: GPT-6.2 Astra — $8 / 1M входа и $40 / 1M выхода; GPT-6 Sol — $2 / $10; для GPT-6 Astra — кэш $1 / 1M, Batch −50%. **Цифры не подтверждены официально.**
Оценка на 1 прогноз `gpt-6.2-astra`: около 500 некэш. входа + около 2000 кэш. + около 420 выхода ≈ **$0.02**, то есть 30 дней ≈ **$0.6–0.7** на человека (через Batch ≈ $0.35). При тарифе 1 666 ₽/мес это порядка 3–4% выручки. `gpt-6-sol` ≈ $0.013 на прогноз (за счёт reasoning-токенов выхода).

## 5. Решение
- **Основная модель: `gpt-6.2-astra`** — лучшее качество авторского русского текста на репрезентативной выборке из 13 генераций; модель актуальна (ноябрь 2026); поддерживает Structured Outputs и Batch.
- **Проверенная запасная: `gpt-6.2-sol`** — качество близкое, скорость выше. Автоматически модель не подменяется: смена только переменной `ASTRODAY_V2_MODEL`.
- Зафиксированный ID: `ASTRODAY_V2_MODEL=gpt-6.2-astra`. Ответ API в каждой генерации возвращает `model: gpt-6.2-astra`, это проверено. В БД сохраняется в `astroday_v2_forecasts.model`.

## 6. Ограничения проверки
- Раунд 2 шёл на промпте v2.1. В v2.2 изменён только блок Луны без курса: модель туда больше не пишет, пояснение вставляет код. Этот промпт реальным запросом не перепроверялся (изменение уменьшает задачу модели).
- 13 генераций на модель — репрезентативная, но не статистическая выборка. Мониторинг: доля непрошедших валидатор (`validation.attempts`) хранится по каждому дню.
