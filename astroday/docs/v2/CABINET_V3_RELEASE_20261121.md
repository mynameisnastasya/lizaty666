- URL: https://lizty666-stage.up.railway.app/app
- Сервис: `liz-ty666-preview` (Railway Function).
- Основной существующий исходник сохранён в виде упакованного снапшота с SHA-256 `63184d63083b6f848317dde0d9005b4fa8236dd2f76ddc55cd6865176937e431`; он не переписывался вручную.

### Отдельный премиальный reader, Railway staging

- URL: https://astroday-personal-monthly-reader-20261121-staging.up.railway.app/
- Сервис: `astroday-personal-monthly-reader-20261121`.
- Версия: `astroday-monthly-reader-v3`, проверяется через публичный `GET /health`.
- Дизайн `astroday/v2/reader-premium-v2.html`, сервер `astroday/v2/monthly-reader.ts`.
- Пять разделов: Мой день, Календарь, Мой месяц, События, Профиль.
- Даты месяца больше не зашиты намертво: сервер выбирает ближайший доступный месячный прогноз из `astroday_monthly_forecasts` по Telegram ID, возвращает `periodStart/periodEnd`; мобильный календарь и поля выбора дат следуют этому диапазону, в том числе после перехода в другой год.
- При отсутствии следующего месяца интерфейс не выдумывает прогноз; возвращается информационная ошибка.
- Подтверждение Telegram `initData`: HMAC-SHA256 и `timingSafeEqual`; вход без действующей подписки блокируется.
- Источник общего астрокалендаря на данный момент охватывает **ноябрь 2026**; это отдельный ресурс, который нужно расширять, когда появятся подтверждённые данные новых месяцев.
