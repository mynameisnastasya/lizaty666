## Диагностические события
| Событие | Вывод |
|---|---|
| `ASTRO_JOIN_OK` | Успешная первая привязка, ошибкой не является |
| `ASTRO_BUTTON_OK` | Факт нажатия. Повторы `astroday_join` подтверждают жалобу №3 |
| `WELCOME_SKIPPED` | Приветствие уже было или профиль не готов. Норма |
| `ASTRODAY_ACCESS_SYNC` с нулями | Нечего синхронизировать. Норма |
| Отдельные HTTP 401 | До r4 — подпись Mini App; после — только невалидные или просроченные сессии. Норма |
