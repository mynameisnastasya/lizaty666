## Подготовлено в коде, пока не включено в рабочие рассылки

- `astroday/v2/moon-guidance.mjs`: транзитная Луна в натальном доме (только если время известно), рекомендация по одному из 12 домов, только её точные аспекты к натальным Солнцу, Луне, Меркурию, Венере, Марсу. Если время рождения неизвестно, натальные дома отключены, аспект к неточной натальной Луне исключён, лунные сутки сохраняются.
- `astroday/v2/offline-fallback.mjs` + feature flag `ASTRODAY_V2_OFFLINE_MODE` в `runtime.mjs` и `queue.mjs`: `off` (по умолчанию), `only` (без платного LLM), `when-exhausted` (только при исчерпании бюджета или 429). Нужны проверенные факты `verified_v2`, полные позиции натальных планет и номер лунных суток; неизвестная дата или непроверенный двигатель приводят к отказу, а не к выдуманному прогнозу.
  - **НЕ выкатывать в production** до end-to-end теста очереди, подписки, доставки и отката. Существующий работающий scheduler — отдельный sha-pinned bundle.
- `astroday/cabinet-v3`: React дизайн 3.1, календарь Ба-цзы «Дни Грабителя богатства», раскрывающиеся события, TypeScript и Vitest. Добавлен отсутствовавший `index.html`, после чего Vite-сборка стала возможна. Это изолированный source snapshot; не заменяет авторизованный Railway Mini App.
- CI `.github/workflows/astroday-unified-release.yml`: проверяет backend Bun, Node offline и TS/Vite/Vitest UI. Прохождение каждой новой версии подтверждать в GitHub Actions.

## Текущие обязательные риски

1. **Telegram Stars**. Правила для цифровых услуг требуют оплаты Telegram Stars внутри Telegram, включая внешние платёжные страницы: https://core.telegram.org/bots/payments-stars . У ASTRODAY есть схема ЮKassa/внешней оплаты. Нужны отдельные тестовые `sendInvoice(XTR)`, `pre_checkout_query`, `successful_payment`, повторная идемпотентная выдача доступа, возвраты `refundStarPayment`, обработка `/paysupport`; старые оплаченные периоды сохранить. Не менять действующую кассу без end-to-end тестов.
2. **Следующие месяцы**. Старый worker полагается на платный AI API, ранее `429 credit_balance_exhausted`; новый offline fallback в единой ветке по умолчанию выключен, пока не протестирован на полной системе. Не обещать пользователям автоматическую готовность всех будущих месяцев.
3. **Floot**. Изолированный демо-проект `abb86812-63e3-467d-b1af-11e2d754037e` упёрся в дневной лимит 100 операций до 21 ноября 22:00 Asia/Ho_Chi_Minh. После восстановления можно переносить UI/Ба-цзы из единой ветки; публикация не должна переписывать оплаты, данные и персональные прогнозы Railway.
4. **Астрология** — символические трактовки, не гарантии конкретных денежных, романтических или семейных событий.
