# ASTROLOGY_ENGINE_SPEC — расчётный движок

**Движок:** `astro-v2-placidus-swe-2.10` (`engine/engine.py`, без изменений, побайтно равен боевому по ответу `/v2/forecast`). Плюс `engine/lunar.py` (`astroday-lunar-v1`) в сервисе-кандидате.

- **Эфемериды:** Swiss Ephemeris (pyswisseph 2.10.3.2). Без `.se1`-файлов работает встроенный Moshier (точность угловых секунд для планет). Независимая сверка: `test/engine-reference.test.mjs`, отклонения ≤ 0,035° по планетам и ≤ 0,006° по куспидам.
- **Зодиак и дома:** тропический зодиак, Placidus. Без тихого перехода на другие дома: при недоступности Placidus (полярные широты) — явный расчёт без домов.
- **Неизвестное время рождения:** домов нет, натальная Луна не используется. Валидатор текста запрещает упоминать дома (`houses_without_birth_time`).
- **Транзиты:** снимок на 12:00 местного времени текущего часового пояса. Активные аспекты с орбами (6° для быстрых, 3° для медленных), состояние сходящийся/расходящийся, точные аспекты и события дня (ингрессии, станции, фазы) на оси UTC внутри местных суток.
- **OpenAI** планеты не считает. Модель получает только выбранные факты (`factsForPrompt`): планеты, аспект, состояние, дом и словарь значений. Время, даты, номера суток, интервалы и градусы модели не передаются и в её тексте запрещены.
- **Персональные данные в OpenAI:** только выбранное обращение (имя или ласковая форма), если человек его не отключил, и грамматический род. Даты, места рождения и Telegram ID не передаются (тест на промпт).
- **Лунный модуль** — LUNAR_CALENDAR_SPEC.md. **Ба-цзы** — BAZI_ENGINE_SPEC.md (чистый JS, эфемериды не нужны).
