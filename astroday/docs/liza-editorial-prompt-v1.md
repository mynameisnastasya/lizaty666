# Редакционный промпт Лизы — `liza-editorial-prompt-v1-20261117`

Код: `shared/liza-editorial.mjs` (`LIZA_SYSTEM_PROMPT`, `LIZA_SCHEMA`, `lizaValidate`, `lizaAssemble`).
Каждая версия текста хранит `editorial_prompt_version`, `editorial_model`, попытки и причины отклонения (`editorial_meta`).

## Разделение ответственности

| Слой | Кто отвечает | Что содержит |
|---|---|---|
| Постоянные правила стиля | промпт (developer-сообщение) | голос, запреты, формат ответа |
| Данные дня | код → JSON (user-сообщение) | смысл каждого факта по разделам, тон дня, известно ли время рождения, начала прошлых прогнозов (чтобы не повторяться) |
| Астрологические факты | **только код** из расчёта движка | «Луна в Водолее акцентирует твой 3-й натальный дом…», «В 10:02 по твоему часовому поясу Солнце образует трин к натальному Сатурну» |
| Персональные данные | **не передаются в модель** | имя вставляется кодом; дата/место рождения, телефон, Telegram ID, платёжные данные в запрос не попадают |

## Описание стиля (по одобренным текстам v6 и собственным сообщениям Лизы в боте)

- **Обращение**: на «ты», лично; имя — в начале и в совете дня (вставляет код).
- **Интонация**: тёплая, уверенная, прямая; без снисходительности и «всевидящего оракула».
- **Ритм**: короткая рубленая фраза рядом с развёрнутой; абзац-раздел 2–5 предложений.
- **Структура** (как у тестеров): `🔮 ДАТА` → ЗАГОЛОВОК ДНЯ КАПСОМ → вход в день → 🔥 Дела, учёба и деньги →
  ❤️ Любовь и отношения → 🌙 Твоё состояние → ✨ Ещё один астроакцент → 🖤 Мой совет на сегодня.
- **Юмор**: бытовая ирония («не устраивай экзамен на телепатию»), без клоунады.
- **Бытовые примеры**: переписки, сроки, суммы, дом, усталость, «одно дело до конца».
- **Эмодзи**: 1–2 на весь текст по делу (🖤 🤎 😁 🔥 ✨), заголовки разделов — фиксированные.
- **Разговорная лексика**: изредка («капец», «фигня»); мат запрещён и отсекается проверкой.
- **Уменьшительные обращения** («котик», «солнышко»): не больше одного на прогноз.

## Запрещено (и проверяется детерминированно, без второй модели)

Названия планет/знаков/домов/аспектов и любые числа в тексте модели (факты вставляет код); гарантии событий,
запугивание, диагнозы, советы по инвестициям/кредитам; «Вселенная…», «теперь самое вкусное», «держись крепче»;
выдуманный опыт Лизы и её клиентов; латиница и служебные слова (json, prompt, инструкции); разметка и ссылки;
слишком короткие/обрезанные разделы; повтор предложения внутри текста; сходство с последними прогнозами > 45 %
или тот же заголовок; больше 6 эмодзи; общий объём > 3 300 знаков (одно сообщение Telegram).

При отклонении — одна повторная попытка с перечнем замечаний; затем задача ждёт (бэкофф) и после крайнего срока
(время доставки или первая попытка + 90 мин; до 5 попыток) уходит расчётный текст с пометкой `calculated_fallback`
и уведомлением владельцам. Политику можно ужесточить: `EDITORIAL_FALLBACK_POLICY=hold`.

## Эталонные примеры

Одобренный формат — тексты v6 тестеров (`liz_tester_forecasts`, `editorial_version=astroday-editorial-v6-20261115`).
Голос — приветствия Лизы в боте (`astroday-tester-welcome-and-kiss`). Новые тексты модели приходят владельцам в группу
вместе с каждым отправленным прогнозом — это и есть поток для редакторской оценки.

## Модель

По умолчанию `gpt-4.1` (уже использовался в проекте для черновиков Лизы, стабилен для русского). Сравнение
на реальном расчёте: переменные `OPENAI_MODEL_TRIAL="gpt-4.1,gpt-6-luna,gpt-6.1-terra"` и
`OPENAI_MODEL_TRIAL_HANDLE=april1joke` у планировщика — черновики каждой модели уходят только владельцам с временем и токенами.
Смена модели — переменная `OPENAI_EDITORIAL_MODEL`, без пересборки.
